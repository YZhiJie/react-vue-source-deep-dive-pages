版本勘误与易错点

网上大量旧资料基于 React 16/17 与 Vue 3.2~3.4，每章标注在 19.3 / 3.5.43 中已经变化的名称与实现，并列出初学者易错点。

这份文档能给你什么 ​

学完本系列后，你应当能够回答下面这些「面试与进阶」问题，并且能在源码中指出对应实现位置：

  1. JSX 背后到底创建了什么？$$typeof 为什么是一个 Symbol？
  2. React Fiber 是什么？为什么它能让渲染「可中断、可恢复」？
  3. 时间切片（Time Slicing）是如何实现的？一帧 5ms 的预算在哪里控制？
  4. Lane 模型是什么？同步更新、Transition、过期任务分别由谁调度？
  5. 虚拟 DOM 的 diff 算法具体怎么移动节点？key 为什么不能用 index？
  6. 一次 setState 从调用到 DOM 改变，中间完整经过哪些函数？
  7. Hooks 为什么不能写在条件语句里？useEffect 的环形链表如何工作？
  8. Vue 3.5 为什么要用 Link 双向链表重写响应式系统？内存涨了还是降了？
  9. Vue 的编译器生成了哪些「优化标记」？Block 树为什么能跳过静态节点？
  10. React 和 Vue 到底差在哪？什么项目该选谁？

如何获取源码 ​

文档中的所有结论均基于以下两个 release tag 的源代码。仓库中 sources/ 目录已被 .gitignore 忽略，如需本地对照请自行下载：

bash
# 方式一：git clone（网络不通时可用方式二）
git clone --depth 1 --branch v19.3.0 https://github.com/facebook/react.git sources/react
git clone --depth 1 --branch v3.5.43 https://github.com/vuejs/core.git sources/vue

# 方式二：下载 tarball
curl -L https://github.com/facebook/react/archive/refs/tags/v19.3.0.tar.gz -o react.tar.gz
curl -L https://github.com/vuejs/core/archive/refs/tags/v3.5.43.tar.gz -o vue.tar.gz

本地运行本站 ​

bash
pnpm install
pnpm docs:dev      # 本地开发（热更新）
pnpm docs:build    # 构建生产版本（输出到 .vitepress/dist）
pnpm docs:preview  # 预览构建产物
