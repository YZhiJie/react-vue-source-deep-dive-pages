# 漫画 · 第 14 话 Diff：为什么必须写 key

> 对应正文：[第 4 章 Diff 算法](../../docs/vue/04-diff-algorithm.md) ｜ 原画：[04-diff-algorithm.svg](./04-diff-algorithm.svg)

## 登场角色

- **阿V**：Vue 绿餐厅主厨，这一话抱来一摞胸牌，专治「上错菜」事故。
- **阿R**：React 餐厅来串门的蓝色机器人，临时客串服务员，在无 key 的座位表面前端崩盘。
- **码叔**：猫头鹰教授，结尾讲清 patchChildren 的九种分派与最长递增子序列。

## 剧情梗概

餐厅满座，队首忽然来了一位新客人 X。阿R 当服务员「只认座位号」：把旧队 A、B、C 的菜按 0、1、2 号端下去，结果 A 的菜上给了 X、B 的菜上给了 A，C 只能对着 3 号空桌——整张桌子的菜和客人全错位。

阿V 的解法是发**胸牌（key）**：服务员从此「认牌不认座」，X 在队首只是新挂一位，A、B、C 对牌入座、一盘不错。

至于乱序换座，她搬出四块指针牌头尾夹击，再让「最长递增子序列」上的人原地不动，只移动其余少数人，把跑堂步数压到最低。

## 分格解读

### 第 1 格 · 无 key 错位现场

旧队是 `[A, B, C]`，头部插入后变成 `[X, A, B, C]`。`patchUnkeyedChildren` 的哲学是「不认人，只认座位号」：公共长度内按下标逐个 patch，A 的 DOM 与组件 state 被原地改成 X、B 改成 A、C 改成 B，多出的 3 号位才新建 C。

所以孩子若带内部状态（输入内容、展开态、勾选态），头部插入、排序、筛选后状态会整体「串」到下一条数据上，界面看起来就像每一行都拿着别人的菜。

尾部追加恰好没事——公共长度内全是原节点。这也解释了为什么用 index 当 key 的 bug 总在测试时复现不了、上线后才爆：开发期数据大多只在末尾追加。

### 第 2 格 · key 是身份证

key 是与位置无关的**身份**：`isSameVNodeType` 要求 type 和 key 全等才认作同一个节点，只 key 相同但标签换了，照样卸载重建。

阿V 给每位客人发胸牌后，服务员照着胸牌对号入座：队首插入 X 时只挂载 X 一人，A、B、C 凭牌命中、原样复用，状态一丝不丢。

胸牌有三条工程纪律：**稳定**（不能用随机数或时间戳，每次身份全变等于全卸全挂）、**唯一**（重复 key 只在 dev 警告，线上 Map 静默覆盖）、**不要用 index**（index 是座位号不是身份，头部插入立刻退回第 1 格）。

### 第 3 格 · 头尾夹击

有 key 的 `patchKeyedChildren` 先摆四个游标：`i` 同时是旧头与新头，`e1` 是旧尾、`e2` 是新尾。头部、尾部两轮同步先把相同的 a、e 就地 patch 掉，尽快夹住真正变化的中段。

夹完之后若旧队先耗尽，中段必然全是新增，按 anchor 批量挂载；新队先耗尽则中段批量卸载。例中旧 `[a b c d e]` 变成新 `[a d b c e]`，夹住的中段恰好是乱序。

乱序段先用 key 到新下标的 Map 认人，再在「新下标到旧下标」的映射上求**最长递增子序列**：b、c 相对顺序没乱，原地不动；只移动 d 一人即可，DOM 操作最少。映射表里旧下标统一加一，0 专门留给「全新节点」。

## 码叔划重点

1. `patchChildren` 按新旧子节点是 text、array、null 组成 3×3 共九种组合分派，只有数组对数组这格进列表 diff。
2. 无 key 按位置复用，头部插入会让整列 state 与 DOM 一起错位；index 当 key 同理。
3. 有 key 先头尾夹击处理相同节点，纯增纯删走批量，乱序部分用最长递增子序列让不动的人最多、移动最小。

## 自测一题

**问：** 头部插入一个新节点时，无 key 和有 key 的两条路径，DOM 操作与组件状态分别发生什么？

**答：** 无 key 走 `patchUnkeyedChildren`：公共长度内按下标原地 patch，A 被改成 X、B 改成 A、C 改成 B，旧组件实例被复用却灌进了下一条数据，state 整体串位，只有末尾新建一个 C。

有 key 走 `patchKeyedChildren`：头部同步立刻在 X 处停下，尾部同步照常，随后判定旧中段先耗尽，于是把 X 按 anchor 插到最前面，**只挂载一次**；A、B、C 凭 key 命中、原地 patch，状态各归其主。

一句话：key 给算法的是「身份」，无身份时它只能赌「坐这个位置的还是同一个人」，头部一动赌局全输。
